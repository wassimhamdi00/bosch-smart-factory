# Jira work-tracking concept

The proposed Jira project uses the key **BSM** and a simple board with To Do, In Progress, Review and Done columns. Ten work items, BSM-01 to BSM-10, represent the planned work packages AP-01 to AP-10.

The [issue CSV](jira_import_example.csv) provides an illustrative work-item mapping with descriptions, role assignments, effort estimates and dependencies. The image is an original board mockup, **not a screenshot or export from a configured Jira instance**.

Reference: [Atlassian Jira project management documentation](https://support.atlassian.com/jira-software-cloud/docs/use-jira-work-management-for-project-management/), accessed 2026-10-09.
